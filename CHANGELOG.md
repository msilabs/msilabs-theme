# Changelog

## 0.1.1

- CSS custom properties (`--name`) now use the property color.
- Blade directive brackets use the punctuation color.
- Python `__magic__` names, f-string `{}` placeholders and shell `$1` style arguments are now colored.
- The language name after a Markdown code fence is colored.
- Added a README badge row and a CI workflow.
